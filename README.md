# 🌸 Bloom Studio — Pixel House Portfolio

An interactive pixel-house portfolio. Hover or tap the house to explore.

## 🚀 How to Run

Open `index.html` in a browser.

- Needs internet once for the pixel font.
- Sound works best via a local server or when hosted.

## 📁 Files

| File | What it does |
|------|--------------|
| `index.html` | Structure (house layers, 3 dialog boxes, sound button) |
| `style.css` | Layout, animations, pixel dialog styling |
| `script.js` | Hover/tap logic, birds, falling petals, sound |
| `links.js` | ✏️ **All links live here** (email, GitHub, LinkedIn, Portfolio, 5 projects) |
| `assets/img/` | House, clouds, flowers, window and dialog images cut from the Figma SVG |
| `assets/audio/ambient.mp3` | Soft music + wind + birds loop (replaceg file, same name) |
